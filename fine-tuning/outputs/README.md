# NeoMint Fine-Tuning Outputs

This directory stores training outputs. These files are generated by the Colab notebooks and are typically large.

## Expected contents after training

| File | Size | Description |
|------|------|-------------|
| `neomint-planner-1.7b-lora/` | ~50-100 MB | QLoRA adapter weights |
| `neomint-planner-1.7b-Q4_K_M.gguf` | ~1.0-1.2 GB | Quantized model for Ollama |
| `training_summary.json` | ~2 KB | Training metrics and configuration |
| `evaluation_report.json` | ~5 KB | Held-out test results |

## Notes

- The GGUF file is too large for regular GitHub. Use Git LFS or distribute separately.
- Add outputs to `.gitignore` except for `training_summary.json` and `evaluation_report.json`.
